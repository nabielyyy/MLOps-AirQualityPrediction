=================================
LK05 — DVC (DATA VERSIONING)
=================================

Fokus:
Melacak perubahan dataset.

Menuju ke:
- Data versioning
- Tracking perubahan data
- Data lineage

Perintah Penting:

Cara cek semua versi
git log --oneline

Inisialisasi:
python -m dvc init

Tracking dataset:
dvc add data/raw

Cek perubahan:
dvc diff

Cek status:
dvc status

Tanda DVC Aktif:
.dvc/

Tanda Dataset Ditrack:
raw.dvc
atau
dataset.csv.dvc

Alur:
Data baru masuk
    ↓
dvc add
    ↓
Hash dataset berubah
    ↓
Versi data tercatat
